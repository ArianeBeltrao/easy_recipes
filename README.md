Easy Recipes App 🍽️
A simple recipe app built with Flutter and Dart. The app allows users to browse recipes by category and save their favorites.

Features
📂 10 different recipe categories
⭐ Favorite recipes feature
🎨 Clean and modern UI

Technologies Used
Flutter
Dart
